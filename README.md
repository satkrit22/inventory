# Comtech Inventory, Sales and Repairs (phase 1)

1. Run `comtech_schema.sql` in Supabase SQL Editor, turn off public sign-ups, create the admin user.
2. Copy `.env.local.example` to `.env.local` and paste the anon key.
3. `npm install` then `npm run dev` (Node 20.9+). Open http://localhost:3000 and sign in.

Phase 1: login, layout, dashboard figures, inventory, spare parts, settings.
